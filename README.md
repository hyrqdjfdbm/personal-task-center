# 个人任务中心 · 前端页面

纯前端页面，使用本地 mock 数据，**无后端接口、无路由、无权限**。

## 在线预览

**https://hyrqdjfdbm.github.io/personal-task-center/**

## 部署到 GitHub Pages

```bash
npm run deploy
```

然后在 GitHub 仓库 **Settings → Pages** 中：

- **Source** 选 **Deploy from a branch**
- **Branch** 选 `gh-pages`，目录选 `/ (root)`

## 本地运行

```bash
npm install
npm run dev
```

## 技术栈

Vue 3 + TypeScript + Ant Design Vue
